> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/risk` — a pure-computation position sizing function that calculates trade volume from fixed % risk and validates margin before MT5 execution.

**Architecture:** Two files — `types.rs` (RiskConfig, RiskDecision) and `lib.rs` (pub fn evaluate). Single synchronous entry point: `evaluate(account, signal, config) -> RiskDecision`. No I/O, no async, no side effects.

**Tech Stack:** rust_decimal (Decimal arithmetic), domain (AccountInfo), ict (TradeSignal, ConfluenceFlags).

mod types;

pub use types::{RiskConfig, RiskDecision};

pub fn evaluate(
    account: &domain::AccountInfo,
    signal: &ict::TradeSignal,
    config: &RiskConfig,
) -> RiskDecision {
    use rust_decimal::Decimal;

    let sl_distance = (signal.entry - signal.sl).abs();

    if sl_distance == Decimal::ZERO {
        return RiskDecision {
            volume: Decimal::ZERO,
            approved: false,
            reason: Some("SL equals entry".to_string()),
        };
    }

    let risk_amount = account.balance * config.risk_pct;
    let raw_volume  = risk_amount / (sl_distance * config.value_per_lot);

    // floor to nearest volume_step
    let volume = (raw_volume / config.volume_step).floor() * config.volume_step;

    if volume < config.min_volume {
        return RiskDecision {
            volume: Decimal::ZERO,
            approved: false,
            reason: Some("volume below minimum".to_string()),
        };
    }

    let volume = volume.min(config.max_volume);

    if account.margin_free <= Decimal::ZERO {
        return RiskDecision {
            volume: Decimal::ZERO,
            approved: false,
            reason: Some("insufficient margin".to_string()),
        };
    }

    RiskDecision {
        volume,
        approved: true,
        reason: None,
    }
}
