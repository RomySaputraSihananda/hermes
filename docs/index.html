Architecture

Hermes is a Cargo workspace with a clean layered design. Each crate has a single responsibility.

hermes/
  bin/
    hermes/        # Live trading engine — reads MT5, places orders
    backtest/       # Walk-forward backtester with PnL reporting
  crates/
    domain/         # Core types: Candle, Side, Symbol, AccountInfo
    ict/            # ICT signal detection: BOS/CHoCH, OTE, OB, FVG, PD arrays
    risk/           # Position sizing: fixed fractional
    mt5-client/     # HTTP client for the MT5 bridge API
    engine/         # Orchestrates ICT analysis → risk → order execution

ICT Strategy

Hermes implements a confluence-based ICT entry model on M15 candles. Each cycle analyzes a rolling window of candles for BOS/CHoCH + PD array alignment, then tries three signal paths in priority order.

Signal Cascade (priority order)

Primary OTE Entry
→ or →
Fallback FVG Entry
→ or →
Fallback OB Entry

All three paths require: BOS/CHoCH confirmed + H1 EMA trend aligned + H4 EMA trend aligned (if enabled). The first path that finds a valid signal wins.

📈

BOS / CHoCH

Break of Structure or Change of Character confirms directional bias before any entry is considered.

🎯

OTE (Primary)

Optimal Trade Entry — price retraces into the 61.8–78.6% Fibonacci zone of the most recent impulse swing.

□

FVG (Fallback A)

Fair Value Gap — last close inside the most recent unmitigated imbalance zone after a BOS.

▲

Order Block (Fallback B)

Last opposite candle before an impulse move. Price re-entering the OB range triggers entry.

🔥

PD Array

Premium / Discount zones. SL placed at PD range_low (Long) or range_high (Short) for tight risk.

🐾

Liquidity Sweep

Sweep of swing highs/lows signals engineered liquidity collection — tracked as an optional confluence flag.

Trade Management

Feature Default Effect
PARTIAL_TP_1R true Close 50% at 1R, remainder runs to TP. Boosts win rate significantly.
PARTIAL_TP_2R true Close 25% of original volume at 2R level.
BREAKEVEN_SL_1R false Move SL to entry after price hits 1R. Protects capital, reduces PF slightly.
TRAILING_2R false Move SL to 1R level when price hits 2R. Parameter sweep found this hurts PF.
FRIDAY_CLOSE_HOUR 21 Force-close all open trades on Friday at or after this hour (UTC). Avoids weekend gap.

Key Findings from Parameter Sweep

H4 Confirm = true

Universally improved PF across all pairs. Eliminates counter-trend noise on lower timeframes.

TRAILING_2R = false

Consistently hurts performance. Cutting winners short is a net negative across all tested pairs.

DOW Filter = true

Skipping Monday/Friday entries reduced losing trades without materially reducing winners.

PARTIAL_TP_1R + 2R

Layered partial exits significantly boost win rate and reduce maximum consecutive losses.

Setup & Deployment

Prerequisites

Rust 1.80+

Install via rustup. Required for building both binaries.

MT5 Bridge

A running MT5 bridge server accessible at MT5_BASE_URL. Provides OHLC data and order execution via REST.

Exness Zero Account

Recommended: zero-spread + $7/lot commission. Set SPREAD_OVERRIDE=0 and COMMISSION_PER_LOT=7.0.

Run a Backtest

# Copy and configure environment
cp .env.example .env
# edit .env with your MT5_BASE_URL and SYMBOL

# Run backtest (fetches 50k M15 candles from MT5)
cargo run --release --bin backtest

Run Live Trading

# Set SYMBOLS (plural) for live mode
# e.g. SYMBOLS=XAUUSDm in .env

cargo run --release --bin hermes

Build Release Binary (Linux static)

rustup target add x86_64-unknown-linux-musl
sudo apt-get install musl-tools

cargo build --release --bin hermes --target x86_64-unknown-linux-musl
# Output: target/x86_64-unknown-linux-musl/release/hermes

Deploy on VPS

# Copy binary and .env to server
scp target/x86_64-unknown-linux-musl/release/hermes user@vps:/opt/hermes/
scp .env user@vps:/opt/hermes/

# Run as a systemd service or with screen/tmux
cd /opt/hermes && RUST_LOG=info ./hermes

GitHub Actions (CI/CD)

The repository includes a workflow at .github/workflows/release.yml. Push a tag like v1.2.0 to trigger a release with pre-built binaries for Linux (musl) and Windows. 

# Tag and push to create a GitHub Release
git tag v1.0.0
git push origin v1.0.0
